Dlaczego klient dodany na jednym urządzeniu nie pojawia się na drugim?

Samo wpisanie klucza API nie wystarczy, jeśli w konsoli Firebase nie utworzyłeś bazy Firestore Database lub jej zakładka Reguły (Rules) blokuje zapis! Sprawdź te 2 kroki w console.firebase.google.com:

  1. W lewym menu kliknij Kompilacja (Build) → Firestore Database i upewnij się, że kliknąłeś Utwórz bazę danych (Create database).
  2. Wewnątrz Firestore Database kliknij na górze zakładkę Reguły (Rules), zamień cały tekst na poniższy i kliknij Opublikuj (Publish):
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /{document=**} {
      allow read, write: if true;
    }
  }
}
Opcja A: Wpisz tylko 2 dane z zakładki „Ogólne” (General) — muszą być identyczne na obu urządzeniach:
